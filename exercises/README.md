# Exercises

The files you copy or import during the workshop, one folder per module. Each module's steps are in `guide.pdf` (or the web guide).

- `module-1/`: the `soc-triage` Claude Code skill, in eight flat files. Module 1 builds the skill part by part and copies these into `.claude/skills/soc-triage/`.
- `module-2/skeleton.json`: the n8n workflow you start Module 2 from. `start.sh` imports it into n8n as `SOC triage (skeleton)`.
- `module-3/skeleton.json`: the Module 3 AI agent with three tools wired. You add the four missing tools the agent's prompt names.

Stuck for more than five minutes on a module? Put your hand up. An instructor has that module's checkpoint, the finished workflow, and will help you import it so you can move on.
