# Module 3

`skeleton.json` is the Module 3 starting point: an AI agent with the case pipeline and three tools already wired (`wazuh_events_for_ip`, `wazuh_events_for_host`, `thehive_related_cases`). The agent's prompt names four more tools that are not wired yet. Add them, following `guide.pdf` (Part 3) and the sticky note in the workflow: `ip_reputation` (AbuseIPDB), `vt_file_report` and `vt_domain_report` (VirusTotal), and `threatfox_search` (ThreatFox). Put the API keys in `lab/.env`.
